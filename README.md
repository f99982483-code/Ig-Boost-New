# Instagram Boost 🚀

A simple Instagram Boost website for placing follower boost orders.

## ✨ Features

* Instagram username input
* Customer name and mobile number
* Multiple follower packages
* Package-based payment amount
* Separate QR code for each package
* Payment screenshot upload
* Google Sheets integration
* Mobile-friendly design

## 📦 Available Packages

| Package       | Price |
| ------------- | ----: |
| 1K Followers  |   ₹28 |
| 5K Followers  |   ₹50 |
| 10K Followers |  ₹100 |
| 20K Followers |  ₹200 |
| 50K Followers |  ₹500 |

## 📱 Order Flow

1. Enter Instagram username
2. Enter customer details
3. Select follower package
4. View the corresponding QR code and amount
5. Complete payment
6. Upload payment screenshot
7. Submit the order

## ⚠️ Note

This project is intended for website/order-management purposes. Payment verification should be completed before fulfilling an order.
